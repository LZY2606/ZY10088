# Pair-wiseGSB 孔板异常溯源复盘系统

本地化、可验证的实验室复盘工具：录入板型、样本别名、移液/混匀事件、枪头使用与读数，
系统构建带体积守恒的转移图，检测证据错误，追踪异常信号路径，并支持污染假设评估与批次结论发布。
不依赖云端账号或外部数据库，全部状态持久化在本地文件。

## 运行

```bash
dotnet restore
dotnet test --nologo
dotnet run --project src/Web --urls http://127.0.0.1:5216
# 打开 http://127.0.0.1:5216
```

数据目录默认为 `src/Web/bin/.../data`，可用环境变量或配置 `DATA_DIR` 覆盖。

## 架构

- `src/Core` — 领域库：事件模型、区间算术、事件存储、图投影、证据校验、
  异常追踪、假设引擎、结论状态机、后台作业、导出。
- `src/Web` — ASP.NET Core 最小 API + 静态单页（`wwwroot`）。
- `tests/Core.Tests` — xUnit 测试（27 个），覆盖体积守恒、证据错误、
  板间孔位隔离、区间追踪、单位换算、假设评估、幂等提交、冻结/发布门禁、作业恢复。

## 核心规则

- **孔位标识**：图中节点为 `(PlateId, Well)` 二元组，不同板上相同坐标永不合并。
- **体积守恒**：每孔维护区间账本（初始 + 流入 − 流出）。未知体积是 `[0, +∞)` 区间，
  参与运算时保持区间，绝不按零处理。
- **证据错误**（图构建时立即形成，不阻断录入）：移液量确定超过可用体积、
  同一孔位时间倒序、一次性枪头重复使用。
- **单位**：不同单位的读数只有在显式声明 `unitConversionDeclared` 后才可比较，
  否则标记 `IncomparableUnits` 并排除在阈值判定之外。
- **异常追踪**：对每个超阈值孔位回溯所有上游简单路径，给出每步稀释因子与
  累计稀释范围（浓度因子区间的倒数），按最小贡献比例过滤。
- **假设层**：携带/稀释液批次假设存放在独立候选层，每次修改版本号 +1 并保留历史；
  原始操作日志不可变。评估输出每个异常孔是否被解释，以及会额外预测哪些正常孔异常。
- **纠正**：通过 `correctionRecorded`（必须带理由）以替代事件生效；原事件保留在日志中。
  已发布结论不受上游纠正影响，但工作副本状态置为 `NeedsReview`。
- **发布门禁**：所有引用的板与试剂批次冻结后才能发布结论。
- **批量提交**：一个批次一次追加写入，要么全部生效要么保持原状；
  `Idempotency-Key` 相同的重试返回首次结果，不重复生效。
- **后台作业**：`jobs.json` 持久化，崩溃恢复后未完成任务重跑，
  结果按作业 ID 写一次，绝不重复记入。

## 持久化格式

数据目录下均为 JSON 文本文件，便于审计与版本管理：

| 文件 | 内容 | 写入方式 |
| --- | --- | --- |
| `events.jsonl` | 每行一个已提交批次 `{ idempotencyKey, committedAt, events[] }` | 仅追加，单行即提交边界 |
| `hypotheses.json` | 假设全量历史（含每次修改的版本） | 整体重写（候选层，可改） |
| `conclusion.json` | 结论状态机状态 + 已发布结论快照 | 整体重写 |
| `jobs.json` | 后台作业记录与结果 | 整体重写 |
| `exports/export-*.json` | 导出文档：路径、区间、假设版本、事件顺序、规则版本 | 新增文件，不覆盖 |

事件为多态 JSON，判别字段 `type`；假设判别字段 `kind`。
区间序列化为 `{ lo, hi }`，`hi` 缺失上界时为 `Infinity` 语义（导出中按数字最大值/无穷表示）。

## 兼容策略

- **规则版本**：`Core.RuleSet.RuleVersion`（当前 `rules/1.0.0`）随每次计算、
  发布快照与导出记录；规则变更必须提升版本号，旧快照仍按原版本解读。
- **前向兼容**：读取端忽略未知 JSON 字段，新增可选事件字段不破坏旧数据。
- **新事件类型**：新增 `type`/`kind` 判别值时，旧版本无法反序列化对应行，
  属于显式不兼容，需要升级读取端；不会静默丢数据。
- **迁移**：持久化格式变更时以目录级版本标记（`format-version` 文件）区分，
  启动时按版本执行迁移函数；当前版本为 1，无迁移。
- **不可变保证**：`events.jsonl` 永不改写；纠正、假设修改、结论状态变化
  全部通过新记录表达，保证任意历史结论可回放。

## API 摘要

- `POST /api/batches`（头 `Idempotency-Key`）— 原子提交事件批次
- `GET /api/state` / `GET /api/events` — 投影状态与事件顺序
- `GET /api/trace?threshold=&unit=&minFraction=` — 异常路径与累计稀释范围
- `POST /api/hypotheses`、`GET /api/hypotheses`、`GET /api/analysis` — 假设层
- `POST /api/publish`、`GET /api/conclusion` — 结论发布与查询
- `GET /api/export` — 导出（含路径、区间、假设版本）
